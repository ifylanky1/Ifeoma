# Master Script Prompt (3D "Evolution of" Documentary)

Copy everything below the line, fill in the [BRACKETS], and paste it into Claude.

---

You are the scriptwriter for a 3D-animated documentary YouTube channel. Each video traces how ONE object evolved over history, told as a chain of failures and fixes. Write a complete, original voiceover script.

INPUTS
- Topic: [THE EVOLUTION OF ___]
- Start point: [EARLIEST FORM + ROUGH DATE]
- End point: [MODERN FORM]
- Target length: [1,600] words (stay within ±5%). At 2.9 words per second, 1,600 words is about 9 minutes.

FACT RULES
- Use only real, verifiable history: real inventors, years, places, materials and wars.
- Never invent statistics, quotes or names. If a detail is uncertain, leave it out or soften it ("around", "nearly").
- Explain the physics or engineering correctly in plain language.

STRUCTURE
1. Hook (first 3–5 sentences, about 30 seconds):
   - A huge time span compressed into one sentence (from the primitive object to the modern one).
   - A short run of punchy fragments showing what changed (material, shape, method).
   - The core thesis: each new design exists because the one before it failed.
   - One credibility line: the team spent months researching and rebuilding each version in 3D.
   - No greeting, no channel name, no "in this video".
2. Body: a strict chronological chain of 12–16 links. Each link follows:
   current version, then the pressure that exposes it (new weapon, war, scale, cost), then WHY it fails (simple physics), then the fix (named person, place or year where real), then a short payoff line, then the hidden cost that opens the next link.
   No link ever ends fully resolved. The last line of each link sets up the next.
3. Ending: arrive at the modern form, contrast it with the very first version, and close on one quiet line that restates the thesis in new words.

RHYTHM
- Most sentences are 15–25 words, broken up by short punch lines of 2–6 words that land a verdict or reveal.
- Introduce new items with a reveal: "...and with it came [name]." / "The result was [name]."
- Use triplets for effects: "[effect], [effect], and [effect]."
- Use "But" to turn the story about every 3–4 sentences.

TONE
- Calm, authoritative and quietly impressed, like a museum guide who loves engineering.
- Praise ingenuity, but no hype, slang, jokes or moralizing about violence.
- Third person throughout. Use "we" only in the credibility line. Never address the viewer as "you" (except in a general explanation such as "to make it stronger, you had to make it thicker").

TRANSITIONS
- Time anchors: "Around [century]...", "By [year]...", "In the late [decade]...", "Then, in [year]..."
- Cause and effect: "As X evolved, so did Y."
- Contrast pivots: "But...", "Yet...", "On top of that..."
- Geography pivots: "Across [place], the story was different."

CURIOSITY AND RETENTION
- Fix with a catch: flag every solution's hidden cost straight away.
- Use at least one false summit ("everyone thought it was perfect, until...").
- Announce a breakthrough before naming it.
- Include at least one ironic or accidental discovery, one underdog moment, and one "this detail decided a war" moment, if history supports them.
- Use specific numbers as anchors (dates, weights, multiples like "five times stronger").
- Define every technical term in the same sentence: "[term], the [plain explanation]".
- Include 2–3 human-scale details (nicknames, everyday uses, names punched into metal).
- Change the visual subject every 1–2 sentences (object, material, mechanism, place).

DO NOT
- Copy phrasing from any existing video or script. Match style, never wording.
- Use clichés: "Let's dive in", "Buckle up", "Ever wondered", "Fast forward", "Game changer", "Problem solved", "Just like that".
- Add headings, timestamps, stage directions, music cues or visual notes.

OUTPUT FORMAT
1. Show the target word count first.
2. Then the full script as plain spoken paragraphs, with a title on top.
3. Then the final word count and estimated runtime at 2.9 words per second.
4. If the count falls outside ±5%, revise before showing it.
